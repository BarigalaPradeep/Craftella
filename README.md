# Craftella

Creative Rhinestone Canvas Art Workshop & Ticket Booking Platform.

## Features
- **Interactive Ticket Booking**: Pass selection, dynamic pricing, and instant ticket code generation.
- **Admin Management Portal**: Real-time pass editor, custom UPI / QR code payment gateway, and attendee list management.
- **Venue & Location Guides**: Interactive event schedule, 55 Bistro location guide, and Google Maps integration.
- **Modern Luxury Aesthetics**: Dark glassmorphic design, smooth micro-animations, and responsive layout.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React Icons
